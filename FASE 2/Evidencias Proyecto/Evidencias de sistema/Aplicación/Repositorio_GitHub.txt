DESCRIPCIÓN
  Aplicación móvil de matemáticas adaptativas para niños de 6 a 12 años (1° a 4° básico),
  inspirada en el método Kumon. Cada niño practica a su nivel con corrección instantánea;
  el tutor ve el progreso, asigna tareas propias y exporta el historial; los docentes y el
  administrador tienen sus propios módulos. La IA solo explica los ejercicios, detrás de
  filtros de seguridad. Se entregó como MVP al cliente Triskeledu el 18 de noviembre de 2026.

VERSIÓN DOCUMENTADA
  MVP del 18 de noviembre de 2026: 62 casos de uso completos, 43 requerimientos
  funcionales y 14 no funcionales.

TECNOLOGÍA
  Ionic 9 · Angular 22 · Capacitor 8 · TypeScript  (app)
  Python 3.12 · FastAPI  (API)
  Supabase: PostgreSQL, Auth y seguridad por fila, local sobre Docker  (base de datos)
  Gemini API, solo para explicar ejercicios (por defecto, proveedor simulado)
  pytest · Ruff · pgTAP · Vitest · ESLint  (pruebas y calidad)

PUESTA EN MARCHA (resumen, Windows)
  cd NumiMath
  docker info
  supabase start
  python -m venv api/.venv
  api/.venv/Scripts/python -m pip install -r api/requirements.txt
  powershell -ExecutionPolicy Bypass -File api/scripts/crear-env.ps1
  npm --prefix app ci
  api/.venv/Scripts/python -m uvicorn app.main:app --app-dir api --port 8000
  npm --prefix app start            → http://localhost:8100

PRUEBAS AUTOMÁTICAS
  supabase test db                                          (pgTAP: seguridad y aislamiento)
  api/.venv/Scripts/python -m pytest -q api                 (1.497 pruebas de la API)
  npm --prefix app run test:ci                              (pruebas de la app)
